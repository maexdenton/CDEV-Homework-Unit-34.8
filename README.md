# 🏠 HomeApi — Сервиса управления "Умным домом"
REST API сервис на базе **ASP.NET Core** для мониторинга и управления компонентами умного дома: комнатными зонами, подключенными устройствами и общими системными параметрами.

Проект выполнен и доработан в рамках учебного курса SkillFactory ([за основу был взят оригинальный проект](https://github.com/SkillfactoryCoding/ASP.NET-Core-Authentication-Authorization-Practices/tree/main/Module%2040.%20Task/AuthenticationService)).

> [!NOTE]
> Итоговый проект по модулю 34.8 курса SkillFactory: Домашнее задание по C# - ASP.NET Core (HW-03)

## 🛠 Стек технологий

- **Платформа:** .NET Core / ASP.NET Core Web API
- **ORM:** Entity Framework Core (Code-First)
- **База данных:** MS SQL Server / LocalDB
- **Валидация:** FluentValidation
- **Маппинг:** AutoMapper
- **Документация:** Swagger (Swashbuckle)

## 🚀 Основные возможности

### 🛋 Управление комнатами (`/Rooms`)
- **Просмотр списка комнат:** Получение информации обо всех добавленных помещениях (с их `Id`, площадью, напряжением и газификацией).
- **Добавление комнаты:** Создание новой зоны с проверкой уникальности имени.
- **Обновление параметров (PUT):** Полная или частичная перенастройка комнаты по ее уникальному идентификатору (`Guid`).

### 📱 Управление устройствами (`/Devices`)
- **Просмотр списка устройств:** Получение списка всех подключенных приборов с привязкой к комнатам и `Id`.
- **Добавление устройства:** Регистрация прибора с валидацией допустимого напряжения и типа подключения (электро/газ).
- **Частичное обновление (PATCH):** Переименование или перемещение устройства в другую комнату.
- **Удаление устройства (DELETE):** Полное удаление устройства из системы по `Id`.

### ℹ️ Информация о доме (`/Home`)
- **Общая сводка:** Получение информации об адресе, площади и состоянии системы.

## 📋 Таблица API Эндпоинтов

| Метод | Маршрут | Описание |
|---|---|---|
| **GET** | `/Home/info` | Получить информацию о доме |
| **GET** | `/Rooms` | Получить список всех комнат |
| **POST** | `/Rooms` | Добавить новую комнату |
| **PUT** | `/Rooms/{id}` | Обновить параметры комнаты по Id |
| **GET** | `/Devices` | Получить список всех устройств |
| **POST** | `/Devices` | Добавить новое устройство |
| **PATCH** | `/Devices/{id}` | Частично изменить устройство (имя / комната) |
| **DELETE** | `/Devices/{id}` | Удалить устройство по Id |
